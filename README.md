# Lembra Aí — agenda online para autônomos

- O profissional cria a conta, cadastra serviços e horários e recebe um link (`?p=seu-nome`).
- O cliente abre o link, vê o app com o nome do profissional, cria a conta uma vez e agenda o horário livre.
- O agendamento cai na agenda do profissional (no app e no calendário do celular via `.ics`), com aviso por notificação, e-mail e WhatsApp.
- 14 dias grátis para o profissional; depois, assinatura mensal pelo Mercado Pago.

Arquivos: `index.html` (app inteiro), `sw.js` (notificações), `supabase/functions/*` (servidor).
